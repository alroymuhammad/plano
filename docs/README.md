# Docs

- `decision/` — engineering decisions. One file per decision: `NNNN-short-name.md`.
- `product/` — product decisions. One file per decision: `NNNN-short-name.md`. Terms in `product/glossary.md`.
- `rules/` — constraints and how-to for working in this codebase. Read before writing code.

Numbers are per folder, increment from the last one, never reuse. Don't edit an accepted decision; add a new one that supersedes it.
